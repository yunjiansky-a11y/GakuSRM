# 安全说明

## 默认保护对象

以下对象会被标记为 `[保护]`，默认不能隐藏：

- 场景根节点、第一层子节点
- 名称包含 `mdl_chr_`、`mdl_env_grp_`、`actor`、`idol`、`camera`、`light`、`stage`、`spot`、`rim`
- 不在 `mdl_*` / 灯光范围内的“列表外对象”

## 强制隐藏

勾选顶部“无视风险”后，保护对象会出现“强制隐藏”按钮。

隐藏以下对象**高风险**，可能导致游戏崩溃：

- 舞台组根节点
- 角色/骨骼根
- 灯光、相机
- 其他对象的父节点

## 建议

- 只在离线/单人场景使用
- 优先隐藏叶子对象（无子节点的道具、装饰）
- 操作前记录对象名，便于恢复
- 出现崩溃时删除 `GakuLoader\plugins\GakuSMM.log` 并反馈最后 20 行
